# دكان العفريت — تطبيق إدارة مبيعات للمتاجر الصغيرة والمتوسطة

تطبيق Android احترافي مكتوب بالكامل بلغة Kotlin باستخدام Jetpack Compose وRoom.

## طريقة التشغيل محلياً
1. افتح مجلد المشروع في Android Studio
2. انتظر مزامنة Gradle
3. اضغط Run على محاكي أو جهاز حقيقي

## البناء التلقائي عبر GitHub Actions
بعد رفع المشروع لمستودع GitHub، يعمل ملف `.github/workflows/build-apk.yml` تلقائياً
ويُنتج ملف APK يمكن تحميله من تبويب Actions > Artifacts.

## الميزات
- نقطة بيع (POS) مع سلة وحساب ضريبة وخصومات وطرق دفع متعددة
- إدارة منتجات وتصنيفات
- تتبع مخزون وتنبيهات نقص الكمية
- تقارير مبيعات وإيرادات وأفضل المنتجات
